# ADR 0001. Модульный монолит

**Статус:** принято · 2026-10-27

## Контекст

Модули из отчёта по проектированию (аутентификация, профиль, биоритмы, задачи, планировщик, расписание, рекомендации, уведомления) тесно связаны: пересчёт расписания затрагивает задачи, профиль и уведомления в одной транзакции. Команда — 2–3 бэкендера, срок — около 10 недель.

## Решение

Один сервис FastAPI. Каждый модуль — пакет в `app/modules/<name>/` со слоями `router` → `service` → `repository` → `models`. Движки алгоритмов (`biorhythm/engine.py`, `planner/engine.py`) — чистые функции без БД, HTTP и «текущего времени».

## Последствия

- Транзакции между модулями — обычные транзакции PostgreSQL, без саг и брокеров.
- Один образ Docker, один набор миграций Alembic.
- Границы модулей держатся дисциплиной: роутер не ходит в БД, движок не знает о БД и HTTP.
