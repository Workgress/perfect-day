# Идеальный День

Планировщик дня с учётом биоритмов и хронотипа: по дате рождения считает физический, эмоциональный и интеллектуальный циклы и раскладывает задачи по самым подходящим часам.

Статус: в разработке.

Контракт спринта аутентификации, разделение задач двух бэкендеров и команды проверки: [backend/docs/auth-contract.md](backend/docs/auth-contract.md).

- Дизайн: [Figma](https://www.figma.com/design/MlCMZlvWvYdCJPNCdCDb53/)
- Стек бэкенда: Python, FastAPI, PostgreSQL, Redis
- Стек фронтенда: React 19, TypeScript, Vite, React Router, Zustand, TanStack Query
